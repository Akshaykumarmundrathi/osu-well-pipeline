About This Dataset
Coordinates resolved via multi-pass PLSS pipeline from scanned Oklahoma oil & gas well permit PDFs (1911–2024). 📍 Precise = dot position interpolated within ¼-section (~330 ft). ◎ Approx = section centroid only (±½ mile); shown as open rings on the map. Pipeline: Google Vision OCR → Gemini Flash AI → PostgreSQL PLSS lookup → 5-pass coordinate resolver.
