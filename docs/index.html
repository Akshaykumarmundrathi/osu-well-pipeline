About This Map
Each pin was read automatically from the original scanned well record and checked against Oklahoma's land-survey grid. 📍 Precise = located within about 330 feet (teardrop pin). ◎ Approx = somewhere within its square-mile section (open ring). Open any pin to view the original document — and if something looks wrong, use ✏️ Verify / Fix; the map repairs itself from submissions.
